Mac에서 만들고, Windows에서 함께 씁니다

Mac에서 만든 PCS 스킬은 호환성 검토를 거쳐 Windows 수강생에게 배포할 수 있습니다. Windows 일반 화면녹화는 PCS 자동 생성 대체물이 아니며, PTS 재료로 활용합니다.

MAC PCS → WINDOWS 배포
호환성 검토 후 배포
웹브라우저 기반·고정 경로 미사용·비밀정보 미포함이면 배포 적합. README_STUDENT.md와 compatibility.json을 함께 제공합니다. Finder/AppleScript 의존·Mac 고정 경로·계정정보 포함은 배포 위험.
WINDOWS 화면녹화 → PTS
녹화는 PTS 재료로
화면녹화 → 작업 절차 텍스트화 → PTS 프롬프트 작성 → $skill-creator 실행 → SKILL.md 후보 → 승인 후 .agents/skills 장착.
