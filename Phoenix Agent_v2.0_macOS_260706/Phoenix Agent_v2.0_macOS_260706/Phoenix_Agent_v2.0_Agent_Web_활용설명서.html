Phoenix Agent v2.0

Agent Web Control Guide

v2.0은 v1.9 안정 봇에 Playwright MCP 기반 agent web 컨트롤 능력을 추가한 버전입니다. 봇은 웹을 조작하고, 결과물은 기본적으로 로컬 outputs에 저장하며, Telegram 전송은 유저 확인 후 진행합니다.

1. v2.0 핵심 흐름

마스터 → Genesis Bot → phoenix command → 전문 봇 → agent web → 결과 생성 → outputs 저장 → Telegram 선택 전송

2. 봇별 담당 agent web

3. Playwright MCP 기준

Playwright MCP는 에이전트가 agent web을 열고 조작하고 검증하는 기본 연결 방식입니다. 실제 안정성은 각 웹의 data-testid, 다운로드 안정성, 상태 API, 실패 처리에 달려 있습니다.

5. 승인 필요 작업

영상 생성, 유료 크레딧 사용, 외부 배포, 세무/치과 상담 결과 전달, 프로젝트 삭제, 여러 agent web 동시 실행은 반드시 마스터 승인 후 진행합니다.
