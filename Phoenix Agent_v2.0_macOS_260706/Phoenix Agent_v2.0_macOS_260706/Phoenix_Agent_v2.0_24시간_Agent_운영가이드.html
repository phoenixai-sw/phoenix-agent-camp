Phoenix Agent v2.0 24시간 Agent 운영 가이드

macOS로컬 노트북 운영하드웨어 세팅

핵심: Phoenix Agent는 MacBook 안에서 실행됩니다. Mac이 잠자기 상태가 되거나 전원이 꺼지면 Telegram 봇도 멈춥니다. macOS는 덮개를 닫으면 기본적으로 잠자기에 들어가려는 성향이 있으므로 전원, 잠자기 방지, 네트워크 조건을 분명하게 확인해야 합니다.

1. 한 문장 결론

노트북이 켜져 있고, 인터넷이 연결되어 있고, 절전/잠자기 상태가 아니며, PM2/OpenClaw gateway가 online이면 봇이 계속 작동합니다. 전원 OFF, 배터리 방전, 절전, 최대 절전, 잠자기 상태에서는 Telegram 봇이 메시지를 보내거나 받을 수 없습니다.

2. 24시간 운영 구조 그림

이 그림에서 전원, 네트워크, PM2/OpenClaw, Telegram 중 하나라도 끊기면 자동 메시지와 응답이 멈춥니다.

3. 먼저 확인할 하드웨어 조건

1전원 어댑터 연결24시간 운영은 배터리만으로 하지 않습니다. MacBook 배터리가 방전되면 봇은 즉시 멈춥니다.
2네트워크 유지Wi-Fi가 잠자기 중 끊기면 Telegram과 모델 호출이 실패합니다. 안정적인 Wi-Fi 또는 유선 LAN 어댑터를 권장합니다.
3덮개 닫기 주의MacBook은 덮개를 닫으면 기본적으로 잠자기에 들어갑니다. 닫힌 상태 운영은 전원, 외부 모니터/키보드/마우스, 설정 조건의 영향을 받습니다.
4발열과 통풍장시간 실행 시 통풍되는 책상 위에 두고, 가방/쿠션/침구 위에 올려두지 않습니다.

4. macOS에서 꼭 바꿔야 할 설정

실제 화면 캡처 대신 유저가 찾아야 할 항목을 그림으로 정리했습니다. OS 버전에 따라 메뉴 이름은 조금 다를 수 있습니다.
1단계. 시스템 설정을 엽니다.
2단계. 배터리 또는 전원 관련 메뉴로 이동합니다.
3단계. 옵션에서 전원 어댑터 연결 시 자동 잠자기 방지 항목을 확인합니다.
4단계. 장시간 운영 시 전원 어댑터를 연결하고, 네트워크가 유지되는지 확인합니다.
5단계. 덮개를 닫고 운영하려면 외부 모니터/키보드/마우스 또는 장비별 클램쉘 조건이 필요한지 확인합니다.

5. 하면 안 되는 운영 방식

상황결과판단
전원 OFFPM2/OpenClaw가 종료됨봇 작동 불가
절전/최대 절전/잠자기네트워크와 프로세스가 멈춤봇 작동 불가
배터리 방전노트북이 꺼짐봇 작동 불가
전원 연결 + 절전 방지 + 인터넷 연결PM2/OpenClaw가 계속 유지됨운영 가능

6. 도우미 실행 방법

도우미는 선택 기능입니다. 먼저 현재 설정을 확인하고, 필요할 때만 전원/절전 설정을 바꿉니다. OS 설정 변경 전에는 내용을 보고 선택해야 합니다.

방법 1. installer 폴더에서 실행

새로 설치하는 유저가 installer 폴더 안에서 실행합니다.

chmod +x ./configure_laptop_awake_mode.command 2>/dev/null || true
./configure_laptop_awake_mode.command

방법 2. updater 폴더에서 실행

기존 봇을 유지하고 v2.0로 업데이트한 유저가 updater 폴더 안에서 실행합니다.

chmod +x ./configure_laptop_awake_mode.command 2>/dev/null || true
./configure_laptop_awake_mode.command

방법 3. Genesis Bot에게 지시해서 진행

직접 설정이 부담스러우면 Genesis Bot에게 아래 지시문을 보냅니다. Genesis Bot은 먼저 확인만 하고, OS 설정을 바꾸기 전에 반드시 보고해야 합니다.

Genesis Bot, Phoenix Agent v2.0 24시간 Agent 운영 설정을 도와줘.

목표:
- 현재 MacBook이 24시간 로컬 Agent 운영에 적합한지 확인
- 전원 어댑터 연결, 잠자기 설정, 덮개 닫힘 조건, 인터넷 연결 상태 확인
- installer 또는 updater 폴더 안의 configure_laptop_awake_mode.command 파일을 찾아 먼저 현재 설정만 확인
- 토큰/API Key/OAuth 값은 절대 출력하지 말 것
- pmset 또는 caffeinate 설정을 바꾸기 전에는 무엇을 바꿀지 먼저 보고하고 승인받을 것
- 마지막에 PM2 online, gateway health, Telegram 자동 메시지 가능 조건을 짧게 보고할 것
