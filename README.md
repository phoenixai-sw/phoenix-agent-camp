# Phoenix Agent Camp

『에이전트의 시대』 책 독자를 위한 **Phoenix Agent v2.0 구독자판** 설치 패키지 배포 저장소입니다.

## 📦 내려받기

👉 **[최신 설치 패키지 내려받기](https://github.com/phoenixai-sw/phoenix-agent-camp/releases/latest)**

위 링크에서 `.zip` 파일 하나를 받으시면 됩니다.

- **지원 환경**: Windows 11
- **설치 방법**: 책의 설치 장 안내를 따라 주세요 — 압축 풀기 → 준비물 셋(텔레그램 봇 토큰 · 대화 모델 API 키 · 봇 연결 키)을 파일에 넣기 → `START_PHOENIX_AGENT.cmd` 더블클릭 → 메뉴 1

## 이 저장소에 관하여

- 이 저장소는 **설치 패키지(zip)의 배포 창구**입니다. 소스 코드는 포함하지 않습니다.
- 피닉스 페이지(에이전트 웹): https://phoenix-page.site
- 문의는 피닉스 페이지 사이트의 안내를 이용해 주세요.
